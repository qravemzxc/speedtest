# Замер скорости интернета

Консольный скрипт на Python, который делает 10 последовательных запросов к указанному адресу,
дожидается полного ответа на каждый и считает:

- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

## Требования

- Python 3.9+
- Сторонние зависимости не нужны — только стандартная библиотека.

## Запуск

```bash
git clone <https://github.com/qravemzxc/speedtest>
cd speedtest
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py https://lh5.googleusercontent.com/brLL_Cjt27_7cecWGylb_WwZjSLNfGwDHjDaNoGTXuJsaqRFg-YQXarbxhNQexc-NxPPPSat7w04l1ShLNpTRzfJixtMg27MfPtK_ZGEFw9T-OHZFS-tR_RPk3xDvcNTUasTLLVXt2_MyJzZpM5L3OhTtyHv5Y_WgxaWnNa6aHB8VudH_yoGiQv3MagICq3bTJGUDg
```

> Для замера лучше брать файлы, предназначенные для тестов скорости (как в примере выше).
> Некоторые сайты (например, Wikimedia) ограничивают частоту запросов и на 2–3 запросе
> отвечают `429 Too Many Requests`.

Опции:

| Опция | Описание | По умолчанию |
|---|---|---|
| `-n`, `--count` | количество запросов | `10` |
| `-t`, `--timeout` | таймаут одного запроса, сек | `30` |

Справка: `python speedtest.py --help`

## Единицы измерения

- **Время** — миллисекунды (мс).
- **Объём** — байты и двоичные кратные: 1 КБ = 1024 Б, 1 МБ = 1024 КБ.
- **Скорость** — основная единица **Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит),
  как её указывают провайдеры и сервисы вроде speedtest. В скобках — **МБ/с**
  (десятичные мегабайты в секунду, 1 МБ = 1 000 000 байт).

## Как считается

- Время запроса — от отправки запроса до получения последнего байта тела ответа
  (включает DNS, установку соединения/TLS и передачу данных). Каждый запрос открывает новое соединение.
- Среднее время = сумма времён / количество запросов.
- Скорость = общий объём (байты × 8) / суммарное время всех запросов.
- Чтобы не получить ответ из кэша и не исказить объём сжатием, отправляются заголовки
  `Cache-Control: no-cache` и `Accept-Encoding: identity`.
- При HTTP-ошибке или ошибке сети скрипт печатает сообщение и завершается с кодом 1.
